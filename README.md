# 🌱 Crop Recommendation System

## 📌 Project Overview

The Crop Recommendation System is a web-based application that recommends suitable crops based on soil nutrients and environmental conditions. It uses machine learning to help users identify crops that may grow well under the given conditions.

## ✨ Features

- Crop prediction based on soil and environmental parameters.
- User-friendly web interface.
- Input fields for Nitrogen (N), Phosphorus (P), and Potassium (K).
- Supports temperature, humidity, soil pH, and rainfall inputs.
- Displays the predicted crop recommendation.
- Web deployment using Vercel.

## 🧪 Input Parameters

| Parameter | Description | Unit |
|---|---|---|
| Nitrogen (N) | Soil nitrogen content | mg/kg |
| Phosphorus (P) | Soil phosphorus content | mg/kg |
| Potassium (K) | Soil potassium content | mg/kg |
| Temperature | Environmental temperature | °C |
| Humidity | Relative humidity | % |
| pH | Soil acidity or alkalinity | pH scale |
| Rainfall | Rainfall amount | mm |

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the Project Folder

```bash
cd YOUR_REPOSITORY
```

### 3. Install Dependencies

Install the dependencies required by your project. For a Node.js application, run:

```bash
npm install
```

### 4. Run the Application Locally

For a Vite-based web application, run:

```bash
npm run dev
```

For a plain HTML, CSS, and JavaScript application, open `index.html` in your browser or use a local development server.

## 🚀 Deployment on Vercel

1. Push your project code to GitHub.
2. Log in to [Vercel](https://vercel.com/).
3. Click **Add New → Project**.
4. Import your GitHub repository.
5. Configure the framework preset and build settings according to your project.
6. Click **Deploy**.
7. Open the generated URL to access your live web application.

## 🌾 How to Use

1. Open the Crop Recommendation System website.
2. Enter the soil nutrient values: Nitrogen, Phosphorus, and Potassium.
